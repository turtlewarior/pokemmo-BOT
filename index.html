How the PokéMMO Ditto bot works

PokéMMO players hunt Ditto because it is the base for breeding. Searching by hand means long stretches of repetitive play. This bot automates the detection step so you do not have to watch every encounter.

The bot captures the game window with mss, then compares each frame to a reference image of Ditto using OpenCV template matching. When the match score passes your threshold, it reacts. Because it works on pixels instead of reading text, it skips the misreads that OCR-based bots suffer from.
